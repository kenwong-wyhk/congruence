F2 Ch5 Congruence

5.1 | Do they fit?

Congruent means the same shape and the same size.

One figure can be slid, turned or flipped so that it fits exactly on the other.

We write $\cong$ and read it "is congruent to". Same shape but a different size is not congruent.

F2 Ch5 Congruence

5.1 | Congruent

Two triangles are congruent if

1. the three pairs of corresponding sides are equal, and

2. the three pairs of corresponding angles are equal.

Same marks show corresponding parts. If any one pair is not equal, the triangles are not congruent.

F2 Ch5 Congruence

5.1 | Definition

The order of the letters tells you which vertex matches which.

1st letter ↔ 1st letter, 2nd ↔ 2nd, 3rd ↔ 3rd. These are corresponding vertices.

So $\triangle ABC \cong \triangle XZY$ is a different statement: there, $B \leftrightarrow Z$ and $C \leftrightarrow Y$.

F2 Ch5 Congruence

5.1 | Reading the statement

If $\triangle ABC \cong \triangle XYZ$, then

Sides

$AB = XY$,  $BC = YZ$,  $CA = ZX$

Reason: corr. sides, ≅ △s

Angles

$\angle BAC = \angle YXZ$,  $\angle ABC = \angle XYZ$,  $\angle BCA = \angle YZX$

Reason: corr. ∠s, ≅ △s

Every line of working carries its reason, written exactly like this.
